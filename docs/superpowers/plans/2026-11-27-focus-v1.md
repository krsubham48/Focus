# Focus v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A native iPhone focus timer with reminders, an optional app guard, a PIN-and-sums override and a day-wise dashboard, installed from Xcode on a free Apple ID.

**Architecture:** All rules and app state live in a Swift package, `FocusCore`, tested on the Mac with `swift test`. The app target holds only screens and thin adapters to iOS (notifications, opening apps, Live Activity, Keychain, lock and call detection, the Shortcuts action). A widget extension draws the Lock Screen countdown.

**Tech Stack:** Swift 6, SwiftUI, Swift Charts, ActivityKit, App Intents, UserNotifications, CallKit, LocalAuthentication, CommonCrypto, XcodeGen 2.48, Swift Testing (package), XCTest (UI tests). No third-party libraries.

**Spec:** `docs/superpowers/specs/2026-11-27-focus-design.md`

## Global Constraints

- iPhone only, portrait only, minimum iOS 26.0.
- Bundle identifiers: `io.github.krsubham48.focus`, `.focus.widgets`, `.focus.uitests`.
- Free Apple ID: no entitlement that needs a paid account (no Family Controls, push, Time Sensitive, Siri). No App Group.
- No network code and no third-party libraries.
- Public repo: never commit a team ID, device identifier, device name or email address.
- Session length 1 to 120 minutes. Presets 1, 5, 10, 20, 30, 60. Initial default 20.
- PIN is exactly 10 digits, stored only as a salted PBKDF2 hash in the Keychain.
- Sums: addition and subtraction, operands 1 to 20, answer never negative, five correct answers.
- Reminders after about 20 s, 2 min, then every 5 min while away, until the session ends. None after one of the six buttons, a screen lock, or during a call.
- "Sessions" and focus time count completed sessions only. A session belongs to the day it started.
- The countdown is computed from the stored end time.
- The Shortcuts action can start the app in the background: startup must not assume a visible screen.
- Lock and call detection use public iOS APIs only.
- UI copy is exactly as written in this plan.

## Review Focus

1. A newer build reading data saved by an older one must keep history (Task 1, `decodesOlderDataWithDefaults`).
2. A button for a missing app shows a message and must not silence the next reminders (Task 3, `failedOpenShowsAMessageAndStillRemindsOnNextExit`).
3. A custom length of 0 or of more than 2 hours is clamped, never rejected with a crash (Task 1, `customLengthIsClamped`).
4. Start tapped twice leaves exactly one session (Task 3, `startingTwiceKeepsOneSession`).
5. Time running out while Override is open records a completed session and closes Override (Task 1, `quitEarlyAfterEndRecordsCompletion`; Task 11, `testTimeRunningOutClosesOverride`).

**Interfaces:**
- Produces:

  - `enum SessionOutcome: String, Codable, Sendable { case completed, quitEarly }`
  - `struct SessionRecord: Codable, Equatable, Identifiable, Sendable { id: UUID; startedAt: Date; endedAt: Date; plannedMinutes: Int; outcome: SessionOutcome }`
  - `struct FocusData: Codable, Equatable, Sendable { active: ActiveSession?; history: [SessionRecord] = []; lastMinutes = 20; onboarded = false; lastGuardRun: Date?; unseenCompletion: UUID?; init() }`
  - `enum SessionRules { static let presets = [1,5,10,20,30,60]; static let allowedMinutes = 1...120; static func minutes(hours: Int, minutes: Int) -> Int; static func presetLabel(_ minutes: Int) -> String }`
  - `enum SessionError: Error, Equatable { case alreadyRunning, noActiveSession, invalidDuration }`
  - `FocusData.start(minutes:now:secondsPerMinute: TimeInterval = 60) throws -> ActiveSession` (mutating)
  - `FocusData.settle(now:) -> SessionRecord?` (mutating, discardable)
  - `FocusData.quitEarly(now:) throws -> SessionRecord` (mutating)
  - `struct FocusStore: Sendable { init(url: URL); static var standard; func load() -> FocusData; func save(_: FocusData) throws }`, standard URL `URL.applicationSupportDirectory.appending(path: "focus.json")`
  - `FocusActivityAttributes(startedAt:)` with `ContentState(endsAt:)`, inside `#if os(iOS)`

All types and members are `public`.

    }

        try FileManager.default.createDirectory(at: url.deletingLastPathComponent(), withIntermediateDirectories: true)
        try Data(text.utf8).write(to: url)
    }

- [ ] **Step 3: Implement**

Nudge delays are 20, 120, then 420 + 300·k, keeping only delays strictly less than `remaining`; each body counts the minutes left at the moment it fires. `clock` rounds seconds up. Derive the hash with PBKDF2-HMAC-SHA256, 32 bytes, 16 random salt bytes:

```swift
CCKeyDerivationPBKDF(CCPBKDFAlgorithm(kCCPBKDF2), pin, pin.utf8.count,
    saltBytes.bindMemory(to: UInt8.self).baseAddress, salt.count,
    CCPseudoRandomAlgorithm(kCCPRFHmacAlgSHA256), UInt32(iterations), &out, out.count)
```

Compare hashes without early exit. `PINVault` stores the JSON of `PINHash`.

    public private(set) var now: Date
    public var showGuardBanner = false
    public var openFailureMessage: String?
    public let vault: PINVault

    public init(store: FocusStore, vault: PINVault, notifier: any Notifying, opener: any AppOpening,
                activity: any ActivityPresenting, secondsPerMinute: TimeInterval = 60,
                clock: @escaping @Sendable () -> Date = { Date() })

    public var session: ActiveSession? { get }
    public var remaining: TimeInterval { get }          // 0 without a session
    public var completedSession: SessionRecord? { get } // the unseen completion

    public func start(minutes: Int) throws
    public func tick()
    public func quitEarly() throws

    public func enteredBackground(hasActiveCall: Bool)

    public func acknowledgeCompletion()

Behaviour: `init` loads and settles, saving if anything changed. Every change to `data` is saved. `start` and `enteredBackground` refresh `now` first. `start` schedules the completion notice and shows the activity. When a session completes, cancel nudges and end the activity, but leave the completion notice. `quitEarly` cancels nudges and the completion notice and ends the activity. `becameActive` ticks, cancels nudges, forgets any button departure and shows the activity if a session runs. `guardTriggered` records `lastGuardRun`, ticks, and if a session runs sets `showGuardBanner` and returns true. The banner clears when the session ends.

struct SeededRNG: RandomNumberGenerator {
    var state: UInt64
    mutating func next() -> UInt64 {
        state &+= 0x9E37_79B9_7F4A_7C15
        var z = state
        z = (z ^ (z >> 30)) &* 0xBF58_476D_1CE4_E5B9
        z = (z ^ (z >> 27)) &* 0x94D0_49BB_1331_11EB
        return z ^ (z >> 31)
    }
}

@Suite struct OverrideTests {
    @Test func sumsStayEasyNeverNegativeAndNeverRepeat() {
        var rng = SeededRNG(state: 1)
        var previous: Sum?
        for _ in 0..<2000 {
            let sum = SumGenerator.next(avoiding: previous, using: &rng)
            #expect((1...20).contains(sum.left) && (1...20).contains(sum.right) && sum.answer >= 0)
            #expect(sum != previous)
            previous = sum
        }
    }

    @Test func sumTextAndAnswer() {
        let sum = Sum(left: 13, right: 4, operation: .subtract)
        #expect(sum.text == "13 − 4" && sum.answer == 9)
        #expect(Sum(left: 7, right: 5, operation: .add).text == "7 + 5")
    }

    @Test func wrongPINStaysOnThePINStep() {
        var rng = SeededRNG(state: 2)
        var flow = OverrideFlow()
        flow.pinEntered(correct: false, using: &rng)
        #expect(flow.step == .enterPIN)
    }

    @Test func wrongAnswerKeepsProgressAndChangesTheSum() {
        var rng = SeededRNG(state: 3)
        var flow = OverrideFlow()
        flow.pinEntered(correct: true, using: &rng)
        guard case let .sum(first, solved: 0) = flow.step else { Issue.record("no sum"); return }
        #expect(!flow.answer(first.answer + 1, using: &rng))
        guard case let .sum(second, solved: 0) = flow.step else { Issue.record("no sum"); return }
        #expect(second != first)
    }

    @Test func fiveRightAnswersThenConfirmThenPINApproves() {
        var rng = SeededRNG(state: 4)
        var flow = OverrideFlow()

            #expect(flow.answer(sum.answer, using: &rng))

        flow.confirm()
